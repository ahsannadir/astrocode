# 2026-10-12 — AstroCode bug-fix pass

Baseline: typecheck + build green, 186 tests passing. Found and fixed 6 issues.

## Fixes
1. **`/commit [msg]` dropped its argument** — `slash.ts` returned `autocommit: true`
   and threw away `arg`; `App.tsx` called `autoCommit(cwd)` with no message, so a
   custom commit message was silently ignored. Changed `SlashResult.autocommit`
   from `boolean` to `string` (empty = default message) and threaded it through
   `App.tsx` (`autoCommit(cwd, res.autocommit || undefined)`).
2. **MCP tool routing was ambiguous** (`src/mcp.ts`) — `executeMcpTool` used a
   naive `startsWith(server + '_')` prefix test, which mis-routes when one server
   name is a prefix of another (`fs` vs `fs_extra`). Now resolves the FULL
   namespaced name against each live connection's actual tool list (longest server
   name first). Also `mcpToolToSchema` now takes the real `serverName` instead of
   `namespaced.split('_')[1]` (which truncates underscore-containing names).
3. **`listSessions()` comparator was not a total order** (`src/sessions.ts`) —
   returned `-1` for equal `updatedAt`, making sort inconsistent and causing a
   flaky `tests/sessions.test.ts` failure ("older" sometimes sorting first).
   Added a monotonic write clock (`nextUpdatedAt()`) so saves are strictly
   increasing, plus a name tiebreak fallback for legacy files.
4. **`openai.ts` readStream ignored the SSE `[DONE]` sentinel** — `break` only
   exited the inner line loop, so the outer read loop kept reading until the
   socket closed. Added a `sawDone` flag to terminate cleanly.
5. **Stale doc count** in `src/serve.ts` header ("15 built-in tools" → 16).
6. **Botched `\u2019` escape** in a `src/subagent.ts` comment.

## Tests added
- `tests/toolbus.test.ts`: MCP namespacing with shared-prefix + underscore server
  names (`fs` vs `fs_extra`), asserting correct routing and `[MCP:fs_extra]` in
  the description.
- `tests/slash.test.ts`: `/commit <msg>` passes the message through; bare
  `/commit` still triggers (empty string, not undefined).

Result: 187 tests, all passing across repeated runs; typecheck + build green.

# 2026-10-12 (later) — syntax highlighting + terminal formatting

Implemented real syntax highlighting and richer markdown for the TUI, with no
new runtime dependencies (still only ink + react).

## New modules
- `src/tui/syntax.ts` — dependency-free highlighter. `detectLanguage(info)`
  maps fence info strings (aliases: ts/tsx→js, bash→shell, yml→yaml, …);
  `highlightCode(code, lang)` returns `Token[][]`, one row per line, memoized by
  language+source (cap 200). Strategies: C-like (JS/TS, Python, Go, Rust, Java,
  C/C++, C#, Ruby, PHP, SQL, shell, Dockerfile, JSON) plus dedicated scanners
  for markup (HTML/XML), CSS, YAML, TOML and Markdown. State carries open block
  comments and multi-line strings (JS templates, Go raw strings, Python
  triple-quotes) across lines.
- `src/tui/markdown.ts` — the renderer. `richLines(text, width)` → `UILine[]`.
  Now supports: fenced code with language label + `│ ` gutter + highlighting,
  headings (h1 bold+underline), bullet/ordered/task lists with nesting and
  hanging indent, blockquotes (`▍`), horizontal rules, GitHub pipe tables with
  alignment, and inline bold/italic/code/strike/links/autolinks. Exports
  `wrapText`, `fitLine`, `inlineSegments`, `tokenColor`; memoized by
  width+source+themeRevision (cap 120).

## Wiring
- `src/tui/theme.ts` — added `syn{Keyword,String,Number,Comment,Function,Type,
  Punct}` + `codeBorder` to the Theme interface and all 12 palettes; added an
  exported `themeRevision` counter bumped by `setTheme()` so color caches
  invalidate on `/theme`.
- `src/tui/MessageArea.tsx` — dropped its inline markdown helpers in favour of
  `markdown.js`; segment rendering now passes Ink's italic/underline/
  strikethrough. Re-exports `UISegment`.
- Plain code identifiers use the normal text color (not `theme.code`) so they
  don't collide with string green. Copy text strips inline markers and keeps
  link targets; code copies without the gutter.

## Tests
- `tests/syntax.test.ts` (21) and `tests/markdown.test.ts` (19); extended
  `tests/theme.test.ts` for the new keys + revision bump. Full suite 228 green,
  typecheck + build clean. Verified visually via a headless Ink render.
